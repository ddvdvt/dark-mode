# Тёмный режим

**Статус: 1.0.0, готово к отправке в Chrome Web Store.** Тексты карточки, ответы для проверки, скриншоты и промо-картинки лежат в [`store/`](store/). Перед отправкой нужно заменить адрес сайта `BASE` в [`extension/lib/brand.js`](extension/lib/brand.js) и `homepage_url` в манифесте (см. ниже).

Расширение для Chrome/Edge, которое включает тёмную тему на любом сайте — быстро, без белой вспышки при загрузке и бесплатно навсегда. Без аккаунта, рекламы и аналитики.

## Возможности

- **Без белой вспышки.** Тема включается до первой отрисовки страницы: в манифесте есть крошечный CSS на `document_start` (тёмный холст), а скрипт успевает прочитать настройки и применить тему за единицы миллисекунд. Время применения видно в окне расширения.
- **Два режима:**
  - **Умный** (по умолчанию). Читает таблицы стилей самой страницы и создаёт рядом с каждой «перекрашенную» копию, где остались только цветовые свойства: фон, текст, рамки, градиенты, тени, `fill`/`stroke`, CSS-переменные (роль переменной — фон, текст или рамка — определяется по тому, где она используется). Копия вставляется сразу за оригиналом, поэтому селекторы, специфичность, `!important`, `@media`, `@supports`, `@layer`, `@container`, вложенные правила и `@keyframes` работают как раньше. Картинки и видео не трогаются, вёрстка не меняется. То, что нельзя переписать (CSS с другого домена, `style="..."`, старые атрибуты `bgcolor`/`color`, `fill` у SVG), обрабатывается запасным путём по вычисленным стилям — порциями в `requestIdleCallback`, с кэшем цветов и учётом наследования (одно правило на каждую пару цветов, а не на элемент).
  - **Быстрый.** Один CSS-фильтр на `<html>` (`invert` + `hue-rotate`, оттенки сохраняются), фото, видео, `canvas`, встроенные плееры и большие фоновые картинки возвращаются в исходные цвета. Работу делает компоновщик браузера, JavaScript почти не нужен. Хорош для очень тяжёлых страниц. Если страница слишком велика для умного режима (больше 60 000 CSS-правил или элементов при полном сканировании), расширение само переключается на быстрый и пишет об этом в окне.
- **Уже тёмные сайты не трогаются.** После загрузки (и ещё раз через 1,5 с — для одностраничных приложений) расширение на мгновение отключает свои стили, смотрит фон холста и фон в центре экрана; если сайт уже тёмный — оставляет его как есть. Кнопка «Всё равно затемнить» в окне меняет решение для сайта.
- **Не ломает страницы.** Меняются только цвета; e2e-тест сравнивает размеры и положение элементов с темой и без — они совпадают. Поля ввода остаются читаемыми (`color-scheme: dark` для встроенных элементов управления). Фреймы на странице тоже затемняются (в быстром режиме их уже инвертирует фильтр родителя, повторно не применяется). Полноэкранное видео не инвертируется. Весь код обёрнут в `try/catch`, повторный запуск скрипта ничего не делает.
- **Окно расширения:** общий выключатель, состояние текущего сайта, «Выключить/Включить на этом сайте», режим для сайта, яркость, контраст и сепия.
- **Расписание:** всегда, как в системе (`prefers-color-scheme`) или по времени (например, с 20:00 до 07:00, переключается само в нужную минуту).
- **Горячие клавиши:** `Alt+Shift+L` — включить/выключить на текущем сайте; «везде» — назначается вручную. Сочетание не занято самим Chrome (у Chrome с `Alt+Shift` заняты I, T, A и N) и не совпадает с сочетаниями популярного аналога (`Alt+Shift+D`/`Alt+Shift+A`), чтобы оба расширения можно было держать при переходе. Изменить: `chrome://extensions/shortcuts` (кнопка есть в настройках).
- **Список сайтов** на странице настроек: «не затемнять», «затемнять всегда», режим для сайта. Правило для `example.com` действует на поддомены. Экспорт и импорт в JSON.
- Интерфейс на русском, английском и казахском.

## Установка (распакованное расширение)

1. Скачайте или клонируйте репозиторий.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`) и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное» и выберите папку `extension/`.
4. Вкладки, открытые до установки, перезагрузите.

## Разрешения и зачем они нужны

| Разрешение | Зачем |
|---|---|
| Скрипт на всех сайтах (`content_scripts`, `<all_urls>`, `document_start`) | Тёмная тема нужна на каждой открытой странице, и её надо применить **до первой отрисовки**, иначе будет белая вспышка. С `activeTab` так нельзя: он требует клика на каждой странице и срабатывает, когда страница уже показана. Скрипт работает только локально: читает стили страницы и добавляет свои. Содержимое страниц, формы и адреса никуда не отправляются и не сохраняются. |
| `storage` | Хранить настройки и список сайтов локально в браузере. |

Больше ничего: нет `host_permissions`, `tabs`, `scripting`, `webRequest`, `web_accessible_resources`. Сетевых запросов расширение не делает (это проверяет `npm test`).

## Конфиденциальность

Всё хранится только в вашем браузере, на сервер ничего не отправляется. В расширении нет аналитики, рекламы и аккаунтов. Подробнее — в [PRIVACY.md](PRIVACY.md).

## Страницы на сайте автора

После установки открывается вкладка `BASE/welcome/dark-mode.html`, после удаления — `BASE/bye/dark-mode.html`, ссылка «Другие расширения автора» ведёт на `BASE/#dark-mode`, а `homepage_url` — на `BASE`. Адрес `BASE` задан в одном месте: [`extension/lib/brand.js`](extension/lib/brand.js) (сейчас там заглушка `https://USER.github.io/REPO/`). После замены поменяйте и `homepage_url` в `extension/manifest.json` — `npm test` проверяет, что они совпадают.

## Производительность

`npm run perf` загружает сгенерированную тяжёлую локальную страницу ([`e2e/heavy.mjs`](e2e/heavy.mjs)): 6 000 элементов, 3 000 CSS-правил (цвета, градиенты, переменные, `@media`, `:hover`), встроенные стили; после загрузки страница ещё 10 раз подряд добавляет по 20 карточек (≈1 000 элементов, как бесконечная лента). Каждый режим — 5 загрузок, в таблице медианы. Долгие задачи (long tasks > 50 мс) собирает `PerformanceObserver` на странице — в них попадает и работа скрипта расширения, он выполняется в том же потоке. TBT — сумма превышений 50 мс.

Chromium 149 (headless, `--disable-gpu`), Windows 11, общий компьютер; результаты в [`e2e/perf-results.json`](e2e/perf-results.json).

| Режим | Тема применена, мс | Перекраска стилей, мс | Запасной путь, мс | Обработка изменений DOM, мс | FCP, мс | load, мс | Long tasks / TBT при загрузке | Long tasks / TBT пока добавляются 1 000 элементов | Самая долгая задача, мс |
|---|---|---|---|---|---|---|---|---|---|
| Выключено (база) | — | — | — | — | 96 | 43 | 0 / 0 | 0 / 0 | 0 |
| Быстрый (фильтр) | 9,9 | — | — | — | 104 | 88 | 0 / 0 | 0 / 0 | 0 |
| Умный | 40,9 | 31,3 | 24,7 | 16,6 | 148 | 182 | 1 / 16 | 0 / 0 | 66 |
| Выключено, страница с CSS с другого домена (база) | — | — | — | — | 104 | 43 | 0 / 0 | 0 / 0 | 0 |
| Умный + CSS с другого домена (проверка всех элементов) | 42,4 | 30,6 | 145,6 (в простое) | 13,2 | 136 | 175 | 1 / 14 | 0 / 0 | 64 |

Как читать:

- «Тема применена» — от старта скрипта до включённой темы, включая чтение настроек. В умном режиме сюда входит перекраска уже загруженных стилей: ~31 мс на 3 000 правил (один проход по CSSOM, кэш разобранных цветов).
- «Выключено» — расширение установлено, но выключено: скрипт только читает настройки и выходит. Нагрузки он не добавляет.
- **Быстрый режим** не создаёт долгих задач вообще; FCP +8 мс. `load` у него позже на ~45 мс — это отрисовка полноэкранного фильтра в программном рендеринге (`--disable-gpu` в безголовом режиме); на обычном компьютере с GPU фильтр дешевле, но это не измерялось.
- **Умный режим** на этой нарочно тяжёлой странице добавляет одну долгую задачу при загрузке (TBT 14–16 мс; самая долгая задача 64–66 мс включает и разбор HTML самой страницей) и сдвигает FCP на ~50 мс: браузер разбирает перекрашенные стили и пересчитывает стили 6 000 элементов. Пока лента растёт, долгих задач нет ни в одном режиме: новые стили перекрашиваются сразу (до следующего кадра), новые элементы — в простое.
- Запасной путь при CSS с другого домена проверяет все 6 000 элементов порциями в `requestIdleCallback` (145 мс суммарно, ни одной долгой задачи).

Честно об ограничениях:

- Сравнение с другими расширениями не проводилось — только с самой страницей без темы.
- Умный режим не заходит внутрь Shadow DOM и не перекрашивает `adoptedStyleSheets`; такие компоненты получают только унаследованный светлый цвет текста.
- Фоновые картинки-текстуры в умном режиме не анализируются (светлая текстура остаётся светлой). Тёмные логотипы и иконки, нарисованные картинкой или CSS-маской, в умном режиме остаются тёмными (проверено вручную на «Википедии»: текст, таблицы, ссылки и карточки читаются, тёмными остались логотип-надпись и иконки меню; в быстром режиме они светлые).
- В быстром режиме цветные эмодзи, иконки-SVG в `<img>` и мелкие иконки-спрайты инвертируются (крупные фото и видео — нет); цвета повторно инвертированных фото слегка отличаются из-за ограничений CSS-фильтров.
- Если страница грузится очень медленно, а сайт выключен в списке, до решения скрипта на долю секунды может мелькнуть тёмный холст (обратная белая вспышка невозможна).
- Служебные страницы браузера и магазин расширений изменить нельзя.

## Разработка

```
npm test              # модульные тесты (node:test): цвета, перекраска CSS, настройки, анализ страницы, проверки релиза
npm run test:e2e      # смоук-тест в установленном Chromium на локальных страницах (playwright-core)
npm run perf          # замер производительности (см. выше), пишет e2e/perf-results.json
npm run zip           # архив dist/dark-mode-<версия>.zip для Chrome Web Store (с проверкой содержимого)
npm run store:images  # скриншоты 1280×800 и промо-картинки в store/ (настоящий интерфейс, локальная страница из store/fixtures/)
npm run icons         # перегенерировать иконки
node scripts/locales.src.mjs   # пересобрать _locales из единого источника
```

Устройство кода:

- `extension/lib/` — чистая логика без `chrome.*` и DOM. Файлы — обычные скрипты (без `import`/`export`), потому что content-скрипты в MV3 не могут быть модулями; они публикуют функции в `globalThis.DarkModeLib`, а страницы и тесты подключают их как модули ради побочного эффекта:
  - `color.js` — разбор цветов (hex, rgb, hsl, oklch/oklab, именованные), перекраска по роли (фон, текст, рамка, тень), цепочка CSS-фильтров;
  - `css-transform.js` — перекраска таблицы стилей (CSSOM → CSS-текст);
  - `settings.js` — настройки, правила сайтов, расписание, решение «затемнять ли», экспорт/импорт;
  - `page-analysis.js` — «уже тёмный ли сайт», запасной путь для элементов, эвристика фото в быстром режиме;
  - `brand.js` — адреса сайта автора (ES-модуль, используется только страницами и service worker).
- `extension/src/content/` — content-скрипты: `preload.css`, `filter-engine.js`, `dynamic-engine.js`, `content.js` (точка входа).
- `extension/src/` — окно расширения, страница настроек, service worker.
- Внешних зависимостей во время работы нет. Для разработки нужен только `playwright-core`, он запускает уже установленный Chromium. Тесты ходят только на локальные страницы (`e2e/fixtures`, `127.0.0.1`/`localhost`).
